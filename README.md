# The Tattoo Co.

A four-page website for a hypothetical minimalist tattoo studio, built as a college assignment while learning HTML5, CSS3 and a little JavaScript. It isn't a real business.

**Live site:** https://relatableree.github.io/tattoo-co/

- `Home.html`: about the studio and featured designs
- `Ourwork.html`: a gallery of past work
- `TheProcess.html`: equipment, inks and sanitation
- `ContactUs.html`: a contact form built with JavaScript (`scripts/contactus.js`); it checks the fields but doesn't send anything

All pages share one stylesheet, `stylesheets/site.css`, and adapt to phone, tablet and desktop widths. Photo credits are listed at the top of that file.
